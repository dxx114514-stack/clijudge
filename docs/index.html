JudgeLite

轻量级命令行在线评测系统

首页 技术支持 GitHub

功能特性

题目管理

创建、编辑、删除题目，支持导入导出JSON格式，方便题库管理。

比赛管理

创建比赛，管理比赛题目，支持多人同时提交评测。

安全沙箱

基于Windows Job Object的安全沙箱，支持时间限制、内存限制、进程数限制。

多语言支持

支持C/C++、Python、Java、JavaScript等多种编程语言。

JSON存储

使用JSON格式存储数据，方便备份、迁移和与其他系统集成。

轻量级

纯命令行界面，无需复杂安装，开箱即用。

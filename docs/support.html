常见问题

Q: 如何编译JudgeLite？

A: 使用CMake编译：

mkdir build cd build cmake .. cmake --build .

或者使用g++直接编译：

g++ -std=c++17 -O2 -o judgelite.exe src/main.cpp -lpsapi -luserenv -lole32

Q: 数据存储在哪里？

A: 默认存储在可执行文件同级目录的 data/ 文件夹下。可以通过设置环境变量 JUDGELITE_DATA_DIR 自定义存储位置。

Q: 支持哪些编程语言？

A: 目前支持以下语言：

  • C/C++ (.cpp, .cc, .cxx, .c)
  • Python (.py)
  • Java (.java)
  • JavaScript (.js)

Q: 如何导入导出题目？

A: 使用以下命令：

# 导出题目 judgelite.exe problem export 1 problem_1.json # 导入题目 judgelite.exe import problem_1.json

Q: 沙箱有哪些安全限制？

A: JudgeLite使用Windows Job Object实现沙箱，支持以下限制：

  • 时间限制（毫秒）
  • 内存限制（MB）
  • 最大进程数
  • 低完整性级别
  • 受限令牌

故障排除

编译错误

  1. 错误: 找不到json.hpp
    确保 json.hpp 文件在 include/ 目录下，或者在项目根目录。
  2. 错误: 找不到Windows API函数
    确保链接了正确的库：-lpsapi -luserenv -lole32
  3. 错误: C++17支持
    确保编译器支持C++17标准，使用 -std=c++17 选项。

运行时错误

  1. 错误: 无法创建数据目录
    检查程序是否有写入权限，或者设置 JUDGELITE_DATA_DIR 到有权限的目录。
  2. 错误: 沙箱执行失败
    确保以管理员身份运行，或者检查Windows安全设置。
  3. 错误: 找不到编译器
    对于C/C++代码，确保g++或gcc在系统PATH中。
